What it is

Why a graph looks good

A pretty graph is really a few things working together. Once you know them you can do it by hand — and you'll see exactly what Graph Styler does for you in one click.

  • 🎨 Color groups Nodes (dots) get colored by folder or tag. Click the settings (gear) icon inside the graph view, open Groups, and set a query (path:"folder" or tag:#tag) with a color.
  • 🧲 Forces How nodes gather or spread. Use the Forces sliders (repel, link distance, center) in that same graph-view panel. More repel + longer links = a wide, spread-out galaxy.
  • ✨ Glow & background The glowing neon look comes from a CSS snippet. Drop a file into Settings → Appearance → CSS snippets and toggle it on. (Ready-to-use code is right below.)
  • 🔗 Shape = links The shape comes from how you link your notes. The more [[wikilinks]] you add, the denser and more constellation-like it gets. A pretty graph is the shape of a well-connected vault.

Doing all this by hand every time is tedious — so Graph Styler applies color, forces, and glow in one preset, and maps the colors to your folders (or tags) automatically.

Try it yourself — glow CSS

Want just the glow without the plugin (an add-on that extends Obsidian)? Save the code below as <vault>/.obsidian/snippets/graph-glow.css and enable it in Settings → Appearance → CSS snippets. Built for dark mode. (Graph Styler does this for you.)

/* graph glow — .obsidian/snippets/graph-glow.css */
.theme-dark .graph-view.color-circle { color: #7dd3fc; }
.theme-dark .graph-view.color-line   { color: #2b4a63; }
.theme-dark .graph-view.color-fill-tag { color: #f472b6; }
.graph-view-content {
  background: radial-gradient(circle at 50% 45%, #16304a, #0b1624 70%) !important;
}
.graph-view-content canvas { filter: saturate(1.35) brightness(1.12); }

Install (beginner-friendly)

💡 Works best in dark mode. Turn it on in Settings → Appearance → Base color scheme: Dark — the glow and colors are built for dark themes.

You'll need the Obsidian desktop app. Graph Styler is now officially listed in Obsidian Community plugins (user-made add-ons), so you can install it directly without BRAT.

  1. 1Go to Settings → Community plugins, turn off Restricted mode, and enable community plugins.
  2. 2Click Browse and search for Graph Styler.
  3. 3Click Install, then enable Graph Styler in your installed plugins list.
https://obsidian.md/plugins?id=graph-styler
  1. 4Done! Open the graph view and click the 🎨 icon in the left ribbon to open the panel.

Use BRAT with moonweave/obsidian-graph-styler only for development builds. For normal use, install from Community plugins.

How to use

  1. 1Open the graph view and click the 🎨 palette icon in the left ribbon — a panel opens on the right.
  2. 2Tap a preset — the graph restyles instantly. Keep the panel open while you move the graph.
  3. 3Open 🎛️ Customize, drag the force/size/color/glow sliders, and 💾 Save it as your own preset.
  4. 4Hit ↩︎ Restore anytime — your original config is backed up automatically.

How do colors map? The preset palette is assigned to your busiest folders (or tags, if you don't use folders). It writes to Obsidian's native graph groups, so you can tweak them in settings too.
