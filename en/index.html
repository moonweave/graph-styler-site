What it is

Obsidian's graph shows notes and their links as dots and lines. Graph Styler changes its colors, background and glow with one preset. Built-in presets leave your physics and sizes alone. It does not analyze your notes or create new links.

Why a graph looks good

A pretty graph is really a few things working together. Once you know them you can do it by hand — and you'll see exactly what Graph Styler does for you in one click.

  • 🎨 Color groups Nodes (dots) get colored by folder or tag. Click the settings (gear) icon inside the graph view, open Groups, and set a query (path:"folder" or tag:#tag) with a color.
  • 🧲 Forces How nodes gather or spread. Use the Forces sliders (repel, link distance, center) in that same graph-view panel. More repel + longer links = a wide, spread-out galaxy.
  • ✨ Glow & background The glowing neon look comes from a CSS snippet. Drop a file into Settings → Appearance → CSS snippets and toggle it on. (Ready-to-use code is right below.)
  • 🔗 Shape = links Graph shape depends on [[links]] and layout settings. Link notes that are genuinely related. A dense or attractive graph does not prove the quality of the knowledge.

Built-in presets change colors, background and glow only. Adjust physics in the graph settings or Customize when you want to. Custom presets also save physics settings, so applying one can change them.

Try it yourself — glow CSS

Want just the glow without the plugin (an add-on that extends Obsidian)? Save the code below as <vault>/.obsidian/snippets/graph-glow.css and enable it in Settings → Appearance → CSS snippets. Built for dark mode. (Graph Styler does this for you.)

/* graph glow — .obsidian/snippets/graph-glow.css */
.theme-dark .graph-view.color-circle { color: #7dd3fc; }
.theme-dark .graph-view.color-line   { color: #2b4a63; }
.theme-dark .graph-view.color-fill-tag { color: #f472b6; }
.workspace-leaf-content[data-type="graph"] .view-content,
.workspace-leaf-content[data-type="localgraph"] .view-content {
  background: radial-gradient(circle at 50% 45%, #16304a, #0b1624 70%) !important;
}
.workspace-leaf-content[data-type="graph"] .view-content > iframe,
.workspace-leaf-content[data-type="localgraph"] .view-content > iframe {
  filter: saturate(1.35) brightness(1.12);
}
/* Keep the input overlay above the filtered renderer. */
.workspace-leaf-content[data-type="graph"] .view-content > canvas ~ iframe,
.workspace-leaf-content[data-type="localgraph"] .view-content > canvas ~ iframe {
  pointer-events: none;
}

Install (beginner-friendly)

Light and dark app themes both work. Presets apply their own graph background, so you do not need to switch the whole app to dark mode.

You'll need the Obsidian desktop app. Graph Styler is now officially listed in Obsidian Community plugins (user-made add-ons), so you can install it directly without BRAT.

  1. 1Go to Settings → Community plugins, turn off Restricted mode, and enable community plugins.
  2. 2Click Browse and search for Graph Styler.
  3. 3Click Install, then enable Graph Styler in your installed plugins list.
https://obsidian.md/plugins?id=graph-styler
  1. 4Done! Open the graph view and click the 🎨 icon in the left ribbon to open the panel.

Use BRAT with moonweave/obsidian-graph-styler only for development builds. For normal use, install from Community plugins.

How to use

These are existing public UI captures. Open an image to see it at full size. The new 0.4.1 group-preservation option and newer 3D selectors are not shown in these earlier captures.

  1. 1Open the graph view and click the 🎨 palette icon in the left ribbon — a panel opens on the right.
  2. 2Tap a preset — the graph restyles instantly. Keep the panel open while you move the graph.
  3. 3Open 🎛️ Customize, drag the force/size/color/glow sliders, and 💾 Save it as your own preset.
  4. 4↩︎ Restore original returns to the graph settings saved before the first application, not the previous step. It overwrites later group and physics edits too; read the confirmation before restoring.

How do colors map? The preset palette is assigned to your busiest folders (or tags, if you don't use folders). It writes to Obsidian's native graph groups, so you can tweak them in settings too.

Save your theme from this panel

  1. 1Start with group colors, background and glow at the top.
  2. 2Use the physics sliders only if you also want a different layout. Changes are live.
  3. 3Enter a name at the bottom and select Save as preset. Check the filter option above it if needed.

Keep the colors you use to classify notes

If you already use group colors, turn on Keep my color groups before applying a preset. New in 0.4.1.

  • Rules, order and colors stay intact, including with Mono and live preview. Glow can still change apparent brightness.
  • Off by default. When on, group color pickers are disabled and local graphs keep their own groups. The setting stays in this vault and is not shared in a preset code.
  • It does not recover previously replaced groups. With it off, presets apply automatic groups and Mono clears groups.

Open the 3D graph

Expand 🧊 3D (experimental), enable the view and select Open 3D graph. Off by default; experimental behavior may change.

Layout and Look are separate: three layouts (Force, Orbital, Globe) and two looks (Original, Deep Space).

3D layouts — swipe or scroll sideways on narrow screens
LayoutWhat it showsKeep in mind
ForceNotes spread by link and repulsion forcesDefault layout. Distances and collision behavior differ from 2D.
OrbitalShells based on shortest link distance from a selected centerSearch for a center; automatic uses the most-connected visible note.
GlobeColor groups placed in regions on a sphere, linked by curved arcsPositions do not represent geography or semantic distance.

Drag to rotate, scroll or pinch to zoom, Shift-drag or right-drag to pan. Hover for a name and highlighted links; click to open the note. Auto-rotate can be turned off.

Reopen the 3D tab after changing filters. It snapshots visible nodes and links from the open global graph; filters do not update live. Without a global graph it uses all Markdown notes, not the local graph. Color groups support path: and tag:; arbitrary queries, arrows and text-fade settings do not all carry over.

Share a theme, save a graph

Share a preset

Select 📋 beside a custom preset to copy its code. The recipient uses Share code → Paste a share code → Import share code, then selects the imported preset to apply it. To save filters and display too, enable Include filters and display in Customize before saving. Local graph filters stay separate.

Export a 2D graph as PNG

Select a global or local graph, then use Export image to save a PNG or copy an image. The panel uses the graph selected most recently. The default folder is Graph Styler exports; the result shows its path and an Open button.

For a post, try 4:5, then Fit whole graph and 2x under More options. Padding avoids cropping notes. Add a date, note count or preset name if useful. Export options do not change graph settings. This export is for 2D global and local graphs.

Already installed?

Use Settings → Community plugins → Check for updates and update Graph Styler. Check that its version is 0.4.1. For manual installation, put the release's main.js, manifest.json and styles.css in the plugin folder.
